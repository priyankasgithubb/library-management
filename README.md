# Library Management System

A Java-based Library Management System built using Object-Oriented Programming principles.

## Features

- Add Books
- Update Books
- Search Books
- Add Members
- View Members
- JSON-based Data Persistence
- Java Streams and Optional API

## Technologies Used

- Java
- Jackson Databind
- Gradle
- JSON

## Project Structure

```
entities/
services/
localDB/
App.java
```
